# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

static HTML/CSS/JS (user choice on a greenfield project; deploy target not yet decided)

## Users

- Primary user: recruiters, fellow developers, and visitors interested in the owner's work, browsing casually from a shared link or profile bio.
- Owner: a web developer showcasing personal projects built with web technologies.

## Product Purpose

A personal portfolio site that showcases the owner's identity, skills, and web development projects. Success means visitors quickly understand who the owner is, what they build, and leave impressed enough to reach out or follow their work. It is a personal creative statement first — the artifact itself should demonstrate craft.

## Positioning

The portfolio itself is the proof of skill: a hand-built, distinctive experience that demonstrates front-end ability through its own design and interaction quality, rather than only describing projects.

## Capabilities and Constraints

- Static site: no server, no backend, no build pipeline required.
- Live weather widget in About pulls current conditions for Hà Nội from Open-Meteo (client-side fetch, no API key, third-party dependency); degrades gracefully to an OFFLINE state when the request fails.
- Owner name/branding to display: **CaQuAnh**.
- Owner is currently studying **Cybersecurity** alongside web development; the skills surface must present it honestly as in-progress, not claimed mastery.
- Projects: no real project content yet — placeholder projects are authored at full fidelity and clearly labeled as placeholders for the owner to replace.
- Content language: **English** (site fully in English per owner decision).
- Contact channels and deploy target still undecided.

## Brand Commitments

- **Visual world (binding):** Pixel font typography + Neo-Brutalism style. All future design work must honor this world — bold flat colors, hard black borders, offset hard shadows, raw blocky layouts; pixel/bitmap display type as the signature voice.

## Evidence on Hand

- None yet: no existing resume content, project assets, screenshots, testimonials, or copy are in the repository. Future design work must not fabricate projects, employers, testimonials, metrics, or client names.

## Product Principles

1. The site is the portfolio — every page must demonstrate real front-end craft.
2. Show real work honestly; never invent projects or claims.
3. Let the work lead; the interface recedes (Experience surface).
4. Fast and accessible by default — a static site has no excuse to be slow.
